# Static Data Management previews

These PNGs are frozen snapshots of this repository's existing native icon
renderers, captured from the loaded bundles. Mii uses frame 430, Photo and Shop
frame 180, and the remaining icons frame 0. They preserve the actual render and
alpha, and avoid mounting animated thumbnail renderers in Data Management.
They are channel previews, not physical save-data icons or verified NAND block counts.
