# System interface font

M PLUS 1p Regular, Medium and Bold are Latin/extended-Latin and punctuation
subsets under the SIL Open Font License in OFL.txt. They approximate the Wii's
system lettering; these files do not contain Rodin fonts. Source:
https://github.com/google/fonts/tree/main/ofl/mplus1p

Rebuild with `scripts/subset-system-fonts.py regular.ttf medium.ttf bold.ttf`.
The 400/500/700 faces cover system menus and portal dialogs. Shop keyboard
typography and the separately maintained date/AM/PM face retain their profiles.
