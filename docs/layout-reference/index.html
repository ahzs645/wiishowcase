Coordinate contract

Top left of the fitted Wii frame, not the browser viewport. One unit = fitted frame height / 480 CSS pixels. Base frames: 640×480 (4:3) and 853⅓×480 (16:9). Capture/test sizes: 640×480, 854×480, 960×720, 1280×720. 854 is a rounded capture width. Native 608/832 × 456 projection and VI output are separate coordinate spaces; see research.json.

A logical slot rectangle, masked border, SVG glyph and button hit area are different bounds. Compare like bounds. Preserve source aspect/crop and record capture state before fitting geometry.

Fonts and clock panes

OFL M PLUS subset approximates Rodin; segmented time glyphs are recreated SVG artwork. Font asset: public/fonts/menu/mplus-1p-bold-latin.woff. 5 clock cells, digit advance 28, colon advance 16, trailing trim 4, SVG height 36. The hour tens cell stays allocated when blank.
